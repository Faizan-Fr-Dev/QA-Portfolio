# OpenCart Manual Testing Project

## Project Overview

This project focuses on manual functional testing of the OpenCart e-commerce application. The objective was to validate key user workflows, identify unexpected behavior, document defects, and summarize the overall testing results.

## Testing Scope

The testing covered major OpenCart features, including:

* User Registration and Login
* Logout and Password Recovery
* My Account and Account Information
* Address Book and Wishlist
* Product Search and Product Details
* Product Comparison
* Shopping Cart and Checkout
* Orders and Product Returns
* Affiliate Account and Newsletter
* Gift Certificates and Special Offers
* Navigation Menus, Header, and Footer
* Currency Change

## Testing Activities

* Reviewed the application features and testing scope.
* Prepared test scenarios and test cases.
* Executed manual test cases and recorded results.
* Documented observed defects with reproduction steps.
* Recorded blocked test cases and their limitations.
* Prepared a test execution summary and test closure report.

**Note:** The results represent recorded test executions. Failed executions require defect investigation, and blocked cases require the necessary prerequisites before execution can be completed.

## Defect Summary

A total of 11 defect reports were documented during testing. The reported issues covered areas such as registration, login/session behavior, product search, keyboard navigation, and quantity validation.

Defect reports include reproduction steps, expected and actual results, priority, status, and related test case references.

## Project Deliverables

This folder contains the following QA documents:

* Test Plan
* Test Scenarios
* Test Cases
* Test Execution Report
* Bug Report
* Test Closure Report

## Testing Approach

Testing was performed manually using defined test scenarios and test cases. Results were recorded as **PASS, FAIL, or BLOCKED**, based on the observed behavior and available test conditions.

This project demonstrates practical experience in manual testing, test documentation, test execution, defect reporting, and test closure reporting for an e-commerce application.
